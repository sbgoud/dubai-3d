Root cause: the scale-bar "nice number" loop in src/ui/ui.js never advanced
(`while (nice * power < metres) nice = nice === 5 ? ... : nice` kept `nice` at
1), so UI.update() spun forever on the very first animation frame. The module
script never finished evaluating, DOMContentLoaded never fired and the browser
main thread was frozen - the page appeared hung with no city.

Fixes pushed in 68fbd61:
1. src/ui/ui.js  - rewritten "nice" number selection (1/2/5 x power), no infinite loop.
2. index.html + src/style.css + public/fonts/ - the render-blocking Google Fonts
   stylesheet is gone; the three typefaces are self-hosted as woff2 with
   `font-display: swap`, so no third-party request can delay first paint.
3. src/world/buildings.js - building indices use a Uint32Array; a full geometry
   flush exceeds the 65535 limit of a Uint16Array and threw on dense chunks.
